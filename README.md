# ana-mate
Gamificação total para criança de 5ª série (estrelas, emojis, frases motivadoras).
Por que esse código é perfeito para você:

Gamificação total para criança de 5ª série (estrelas, emojis, frases motivadoras).
10 níveis A exatamente como pediu (A1 → A10).
Ao terminar A10 com 80%+ de acerto → muda automaticamente para nível B (dezenas e unidades).
Questões 100% aleatórias a cada fase (nunca repete a mesma sequência).
Escalável – basta editar a função get_parametros_nivel para adicionar níveis C, frações, divisão, etc.
Sessão salva o nível do aluno (não perde progresso ao fechar o navegador).
Código limpo e comentado para você continuar evoluindo sozinho.
